# ADR-001: Dual AI Provider (Google Gemini + Local Ollama) & Deterministic BM25 Circuit Breaker

- **Status:** Accepted
- **Date:** 2026-10-20
- **Deciders:** SmartDesk AI Architecture Team (`Owner 1: AI & RAG`)

## 1. Context
SmartDesk AI requires sub-1.5s grounded RAG responses and automated ticket copilot capabilities while operating reliably under three real-world constraints:
1. Third-party cloud LLM APIs (Google Gemini Free Tier) enforce strict rate limits (15 RPM / HTTP 429 `ResourceExhausted`) and occasional latency spikes.
2. Retired model endpoints (`gemini-1.5-flash`, `text-embedding-004`) return HTTP 404 when deprecated by cloud providers.
3. Offline grading environments or air-gapped developer machines may have no external internet or API key configured.

## 2. Decision
We implemented a **3-tier resilience architecture** across `llm_service.py`, `embedding_service.py`, and `fallback_service.py`:
1. **Tier 1 — Primary Cloud Provider (`AI_PROVIDER=gemini`):** Uses `gemini-3.5-flash-lite` (with automatic in-flight fallback to `gemini-2.5-flash-lite` on model errors) and `gemini-embedding-001`, wrapped in a strict `4.0s` `asyncio.wait_for` timeout.
2. **Tier 2 — Local Open-Weights Provider (`AI_PROVIDER=ollama`):** Uses `qwen2.5:3b` and `nomic-embed-text` over `httpx.AsyncClient` (`http://localhost:11434`), enabling 100% local, zero-cost inference with no external rate limits.
3. **Tier 3 — Stateful Cost-Guard Circuit Breaker & Pure-Python Okapi BM25 Fallback:** Any timeout (`> 4.0s`), network failure, or HTTP 429 trips a 60-second cooldown (`cooldown_until = now + 60s`) and routes queries to `FallbackService` (Okapi BM25 over `backend/data/seed_faq.json`) and deterministic SHA-256 768-dim unit vectors, returning HTTP 200 with `"is_fallback": true`.

## 3. Alternatives Considered
- **Cloud-Only Gemini without Local Fallback:** Rejected because a missing API key or 15 RPM quota exhaustion during a live defense or automated evaluation run would break the application.
- **Heavy Local HuggingFace / PyTorch Sentence-Transformers Inside FastAPI Process:** Rejected because bundling multi-gigabyte PyTorch CUDA dependencies bloats Docker build times and RAM usage (> 4GB), whereas Ollama + pure-Python BM25 keeps the backend container lightweight.

## 4. Consequences
- **Positive:** 100% uptime guarantee (`0` unhandled HTTP 500 errors when LLM fails); seamless toggling between cloud speed (~920ms) and local privacy/unlimited quota (Ollama).
- **Negative / Trade-off:** Embeddings generated by `gemini-embedding-001` (3072-dim) and `nomic-embed-text` (768-dim) have different dimensions, requiring `python backend/scripts/reembed_chunks.py` when switching providers on an existing database.
