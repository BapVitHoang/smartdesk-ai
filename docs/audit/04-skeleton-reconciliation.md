## 2. Verification of "DECISIONS ALREADY MADE"

1. **Model Name & GA Verification:**
   - **Verification:** Verified live via `google-genai` Python SDK against Google API. `models/gemini-3.5-flash-lite` exists and successfully generates content.
   - **Decision:** Primary model is `gemini-3.5-flash-lite`. Optional fallback is `LLM_FALLBACK_MODEL = ""` (empty by default). Config token prices: Input `$0.30/1M`, Output `$2.50/1M`. No silent alias rewriting.
2. **Ticket Category Canonical Value & Alias:**
   - **Decision:** Canonical is `"Bug Report"`. `"Technical Bug"` is accepted as an input alias and normalized to `"Bug Report"`.
3. **OAuth2 Architecture:**
   - **Decision:** Hybrid approach. Real Google ID token verification when `GOOGLE_OAUTH_CLIENT_ID` is set; Demo login for test accounts (`admin@smartdesk.ai`, `an.nguyen@company.vn`) when `DEMO_LOGIN_ENABLED=true`. Both issue the same HS256 JWT and enforce identical RBAC.
4. **Team & Ownership:**
   - **Decision:** 3 developers (Owner 1: AI/RAG/Telemetry, Owner 2: Platform/Auth/Tickets, Owner 3: Frontend UX/DevOps/QA + Integration Owner).
